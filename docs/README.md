# Prewalk documentation

## Start here

- [`prewalk-vs-omp.md`](prewalk-vs-omp.md) explains what Prewalk is, who it is
  for, how one run works, and where it differs from Oh My Pi. It is the
  plain-language guide for people evaluating or using the extension.

## Current documentation

- [`../README.md`](../README.md) covers installation, configuration, commands,
  lifecycle, optional integrations, limitations, and development checks.
- [`analytics.md`](analytics.md) explains local receipts, recorded spend, and
  price-based estimates.
- [`architecture/repository-structure.md`](architecture/repository-structure.md)
  explains the module boundaries and dependency direction.
- [`architecture/host-event-correlation.md`](architecture/host-event-correlation.md)
  records the exact technical rules for delayed Pi events and run isolation.
- [`../benchmark/README.md`](../benchmark/README.md) describes the opt-in paid
  benchmark and its safety boundary.

The guide and current architecture files are included in packed installs. The
files under `plans/`, `research/`, and `archive/` are historical engineering
records or evidence appendices. They are kept separate from the user docs and
are not setup instructions, compatibility promises, or release notes.
